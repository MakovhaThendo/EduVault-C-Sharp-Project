# EduVault

EduVault is a desktop-based student funding management system developed in C# using Windows Forms. It is designed to streamline and standardise the end-to-end funding application lifecycle, from student onboarding through to document submission and application tracking.

The system provides a structured workflow for capturing student information, managing funding requests, and handling supporting documentation in a modular and user-friendly interface.

---

## Key Capabilities

- Centralised student profile management (personal, academic, and contact information)  
- Structured funding application workflow with configurable assistance categories  
- Secure document management module for uploading and organising required supporting files  
- Application tracking with reference generation and status visibility  
- Password reset and account recovery functionality  

---

## Architecture & Design

- Layered form-based architecture (modular Windows Forms design)  
- Event-driven UI logic for user interactions and workflow progression  
- File handling for local document storage and retrieval  
- Separation of concerns across UI components and business logic handlers  

---

## Technology Stack

- C# (.NET Framework)  
- Windows Forms (WinForms)  
- Visual Studio IDE  

---

## Project Objective

This project demonstrates applied knowledge of desktop application development, UI/UX workflow design, and event-driven programming. It simulates a real-world administrative funding system with emphasis on usability, modularity, and process flow integrity.
